## Soft-404 / redirect illusion

Across llms.txt, agents.md and both MCP paths: 20/66 naive final-200 positives fail structural verification (30.3%). 11/60 domains have at least one such false positive.
False positives include unrecognized JSON/text, truncation and WAF bodies, not only HTML/redirects; see the separate illusion column.
The narrower HTML/root/login/parked illusion count is 8/66 (12.1% of naive positives).

## Reproducibility and limits

Single observation per path, GET, ordinary TLS validation, explicit redirects (max 5, no HTTPS downgrade), no browser/JS, no retries or API keys. One host task at a time; global hostname spacing also covers redirect destinations. Configuration is embedded in raw JSON.
Bodies are capped; truncated artifacts are unverified, so large llms-full documents can be undercounted. Timeouts, TLS errors and blocking are unknown availability, not proof of absence.
Markdown verification checks structure, not authorship, correctness or agent utility. MCP discovery paths have no universal descriptor schema; the versioned heuristic requires HTTP transport plus endpoint URL (or a map/list of such servers), and does not handshake with servers. Plugin checks cover v1 core fields, not full specification conformance. Redirect-to-home catches root redirects but not every possible parked site.
Robots group extraction is descriptive, not an RFC-complete path-permission engine. This study does not establish MCP protocol support or universal agent readiness.

## Public dataset and reproduction

The committed [survey-2026-11-17-summary.json](benchmarks/survey-2026-11-17-summary.json)
records all **420 probes** across all 60 domains in **227,419 bytes**.
Only raw text/base64 response bodies were removed. Self-described column tables
retain every URL, redirect status/location/latency, content type, captured byte
length, full SHA-256 (including any desired prefix), truncation, classification,
verification evidence, robots AI rules, configuration, and aggregate statistic.
The historical full raw capture (roughly 25 MB) is not included in this repository.
A hash identifies captured bytes; it does not let a reader reclassify an omitted body.

From this package directory, reproduce full raw captures on demand:

```sh
export PYTHONPATH=src
python3 -m agent_ready_radar scan --targets-file benchmarks/cohorts.json --workers 6 --spacing .3 --timeout 8 -o benchmarks/survey-2026-11-17.json
python3 -m agent_ready_radar summarize benchmarks/survey-2026-11-17.json -o new-summary.json
```

This repeats the measurement procedure, not the historical responses; only scan
authorized targets. For an offline reproduction of the published tables/card,
pass the committed summary to `report` or `octopus-card` instead.
See [README.md](README.md#public-survey-data-and-reproduction) for the summary
format and interpretation limits. The classification logic is unchanged from
the original dated study.
